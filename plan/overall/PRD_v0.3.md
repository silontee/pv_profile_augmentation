# PV Profile Augmentation PRD (전체)

- 문서 버전: `v0.3`
- 작성일: `2026-02-27`
- 문서 정책: 기존 문서 덮어쓰기 금지, 버전 올린 새 문서로 추가

## 1. 프로젝트 목표

핵심 목표는 `rps_rawdata`와 실제 세부 발전량 데이터 간 간극을 메우는 것이다.
현 단계는 배포가 아니라 자동화 파이프라인 완성에 집중한다.

## 2. 진행 계획 (트랙 분리)

### 2.1 크롤링 트랙
- data.go.kr 원천 CSV 증분 수집 안정화
- 상태 파일 기반 재실행/중단복구 검증
- 수집 실패 로그 기준 재시도 정책 확정

### 2.2 전처리 트랙
- Polars 기반 통합/정제 파이프라인 고정
- 컬럼 스키마/타입/결측 처리 규칙 확정
- 산출물 파일 규약(입출력 계약) 문서화

### 2.3 통계적 증강 트랙
- `rps_rawdata`와 세부 데이터 간 간극 정의
- 증강 대상 변수 및 제약조건 정의
- 후보 통계 방법론 비교/선정(아직 미확정)

## 3. 현재 진행 상태

- 크롤링: 동작 중, 원천 CSV 수집 완료 상태 유지
- 전처리: 통합 파일 생성까지 확인, 파이프라인 표준화 진행 필요
- 통계적 증강: 문제정의 완료, 방법론 선택/검증은 미착수

## 4. 현재 블로커

1. 과거 지오코딩 코드 유실로 재구현 필요
2. `http_400` 오류 원인별 처리 규칙 미확정
3. 통계적 증강 방법론 미선정

## 5. 문서 운영 규칙

- 전체 계획 문서: `plan/overall/PRD_v0.3.md`
- 세부 계획 문서: 각 트랙 폴더에서 독립 버전 관리
- 다음 수정부터는 반드시 새 버전 파일 생성
