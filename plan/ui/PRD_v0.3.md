## 2. 버그픽스 상세: 토지피복 색상 미표시

### 원인

`landcover.py`에서 EGIS WFS `lv2_2025y` 레이어의 중분류 코드 필드명을 `lcm_cd`로 잘못 가정.
실제 WFS 응답의 필드명은 **`l2_code`**.

```python
# v0.2 (잘못됨)
code = str(props.get("lcm_cd", ""))[:1]

# v0.3 (수정)
code = str(props.get("l2_code", ""))[:1]
```

### 증상

- `lcm_cd` 키가 없어 항상 `""` 반환 → fallback 색상 `#9ca3af`(회색)만 적용
- 지도에서 토지피복 폴리곤이 모두 동일한 회색으로 표시됨

### 실제 WFS 응답 properties 구조

```json
{
  "l2_code": "150",
  "l2_name": "교통지역",
  "img_date": "2024-12-30Z",
  "img_name": "항공정사영상",
  "gid": 1478316,
  "inx_num": "377092",
  "etc_info": "",
  "ud_info": "2025년 사업-세분류 토지피복지도"
}
```

### 색상 매핑 (l2_code 첫 자리 기준)
